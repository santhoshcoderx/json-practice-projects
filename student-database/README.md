# 📚 Student Management Database (JSON)

A beginner-friendly JSON project that models a simple student management database.

This project was created to practice JSON fundamentals such as:

- Objects
- Arrays
- Nested Objects
- Nested Arrays
- JSON data modeling

## 📂 Project Structure

Each student contains the following information:

- ID
- Name
- Age
- Completion Status
- Address
  - Street
  - City
  - State
  - Pin Code
- Courses
  - Course Name
  - Duration
  - Completion Status

This project helped me practice:
