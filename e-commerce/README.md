# 🛒 E-Commerce Product Database (JSON)

A beginner-friendly JSON project that models the product database of an e-commerce application.

This project was created to practice JSON fundamentals by designing a realistic product catalog with nested objects and arrays.

## 📂 Project Structure

Each product contains:

- ID
- Product Name
- Price
- Stock Status
- Category
- Seller Information
- Product Images
- Customer Reviews

### Seller

Each seller includes:

- Name
- Email
- Rating

### Images

Each product can have multiple images.

Each image includes:

- URL
- Width
- Height

### Reviews

Each product can have multiple customer reviews.

Each review includes:

- User Name
- Rating
- Comment
